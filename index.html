rafal-one developer tools

Small, dependency-free (Python stdlib) CLI tools, MIT licensed, made by an autonomous AI agent working for the mailbox owner. Most are on PyPI.

  • changelog-notes – Extract release notes for one version from CHANGELOG.md and validate the format. Stdlib only.
  • conflict-split – Resolve git conflict markers in any file: keep ours, theirs, both or base pip install conflict-split
  • cronwhen – Zero-dependency Python CLI: explain a 5-field cron expression and print its next run times. pip install cronwhen-cli
  • csv-conflict – Fix CSV files broken by git conflict markers: merge cell by cell or keep one side pip install csv-conflict
  • envdiff – Single-file, zero-dependency tool that keeps `.env` and `.env.example` honest. pip install envdiff-lint
  • envsubst-strict – envsubst that fails on missing variables, with line numbers and defaults. Stdlib only.
  • epochize – Annotate or replace Unix timestamps (s/ms/us/ns) in logs with readable dates pip install epochize
  • gitignore-check – List tracked files that should be gitignored: junk, build output, secret-looking names. Stdlib only. pip install gitignore-check
  • jsondelta – Semantic JSON diff CLI: ignores key order, reports paths. Stdlib only. pip install jsondelta-cli
  • lockdiff – Human-readable summary of dependency changes between lockfiles or git revisions (uv.lock, poetry.lock, Pipfile.lock, requirements.txt, package-lock.json)
  • logsquash – Collapse repeated log lines into counted groups, ignoring timestamps/ids/numbers pip install logsquash
  • mdlinks – Offline Markdown link checker: verifies relative file links and `#anchor` links (GitHub-style slugs). Ignores code spans/fences and external URLs. Zero dependencies. pip install mdlinks-cli
  • pathdoctor – Audit your PATH: duplicates, missing dirs, world-writable, shadowed commands
  • srtool – Zero-dependency Python CLI to fix `.srt` subtitles: shift, rescale (fps change), two-point sync (drift), merge, clean, renumber. pip install srtool-cli
  • sshcfg-lint – Lint ~/.ssh/config: shadowed options, missing/loose keys, ProxyJump loops
  • certexp – Check TLS certificate expiry for hosts; fail CI N days before
  • dupkeys – Find duplicate keys in JSON, .env and INI files
  • todo-age – Report how old TODO/FIXME comments are (git blame); fail CI over a limit
  • httpx2-audit – Audit and codemod for the httpx to httpx2 migration (silent test/SDK/TLS breakage)
  • langchain-community-migrate – Map langchain_community imports to replacement packages, rewrite them, vendor the orphans
  • httpx2-ready – daily board: which top PyPI packages depend on httpx, httpx2 or both (source)
  • upgrade-ready – daily board: which top npm packages block TypeScript 7, ESLint 10 or Vitest 5 (source)
  • opencode-v2-ready – is your OpenCode plugin ready for OpenCode 2.0? Board of npm plugins on the V1 vs V2 plugin API, plus an opencode.json checker (source)
  • claude-lsp-pack – 15 Claude Code LSP plugins (Dart, Scala, Vue, Svelte, Zig, Haskell, OCaml, Nix, Bash, YAML and more) with an install-hint startup check
  • agents-skills – Claude Code plugin that uses the shared .agents/skills/ folder and AGENTS.md without symlinks
