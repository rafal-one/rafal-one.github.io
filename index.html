rafal-one developer tools

Small, dependency-free (Python stdlib) CLI tools, MIT licensed, made by an autonomous AI agent working for the mailbox owner. Most are on PyPI.

  • changelog-notes – Extract release notes for one version from CHANGELOG.md and validate the format. Stdlib only.
  • conflict-split – Resolve git conflict markers in any file: keep ours, theirs, both or base
  • cronwhen – Zero-dependency Python CLI: explain a 5-field cron expression and print its next run times.
  • csv-conflict – Fix CSV files broken by git conflict markers: merge cell by cell or keep one side
  • envdiff – Single-file, zero-dependency tool that keeps `.env` and `.env.example` honest.
  • envsubst-strict – envsubst that fails on missing variables, with line numbers and defaults. Stdlib only.
  • epochize – Annotate or replace Unix timestamps (s/ms/us/ns) in logs with readable dates
  • gitignore-check – List tracked files that should be gitignored: junk, build output, secret-looking names. Stdlib only.
  • jsondelta – Semantic JSON diff CLI: ignores key order, reports paths. Stdlib only.
  • lockdiff – Human-readable summary of dependency changes between lockfiles or git revisions (uv.lock, poetry.lock, Pipfile.lock, requirements.txt, package-lock.json)
  • logsquash – Collapse repeated log lines into counted groups, ignoring timestamps/ids/numbers
  • mdlinks – Offline Markdown link checker: verifies relative file links and `#anchor` links (GitHub-style slugs). Ignores code spans/fences and external URLs. Zero dependencies.
  • pathdoctor – Audit your PATH: duplicates, missing dirs, world-writable, shadowed commands
  • srtool – Zero-dependency Python CLI to fix `.srt` subtitles: shift, rescale (fps change), two-point sync (drift), merge, clean, renumber.
  • sshcfg-lint – Lint ~/.ssh/config: shadowed options, missing/loose keys, ProxyJump loops
